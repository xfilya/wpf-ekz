# Чудо Обувь — подготовка к демоэкзамену

Текущее учебное приложение на C#, .NET 10, WPF, Entity Framework Core и SQLite по КИМ 09.02.07-2-2027.

## Запуск

Откройте `WpfAppTest.slnx` в Visual Studio с компонентами разработки WPF и .NET 10. Либо выполните из корня репозитория:

```powershell
dotnet restore WpfAppTest/WpfAppTest.csproj
dotnet run --project WpfAppTest/WpfAppTest.csproj
```

Готовая учебная база находится в `WpfAppTest/database.db`, изображения — в `WpfAppTest/Assets`. При сборке они копируются рядом с приложением. Приложение читает копию базы в выходной папке.

## Текущее состояние

Подключена база с 31 товаром, 92 строками остатков, 20 пользователями, 10 заказами и 30 позициями заказов. Каталог показывает товары, категории, производителей, состав, цены, наличие и фотографии. Для проверки заглушки в `MainWindow.xaml.cs` пока оставлена строка с `missing.png` для первого товара.

Следующие этапы подготовки: скидка 25%, авторизация, поиск и фильтры, карточка товара, корзина, оформление и управление заказами.

## Памятка и исходные данные

- `Docs/Памятка_Чудо_Обувь_перед_экзаменом.docx` — самопроверка, SQL, код каталога, объяснения и дальнейший план.
- `TrainingData/*.xlsx` — четыре исходные таблицы для повторения импорта.
- `TrainingData/01_schema.sql` — создание восьми целевых таблиц в новой пустой базе.
- `TrainingData/02_prepare_names.sql` — исправление четырёх известных расхождений после импорта CSV во временные таблицы.
- `TrainingData/03_import.sql` — перенос данных из временных таблиц в целевые; каждый `INSERT` выполняется один раз.

Подробный порядок и ожидаемые количества строк приведены в памятке. SQL проверен на исходных данных, текущий проект собирается без ошибок и предупреждений.
